## 先把换算搞清楚：1M带宽是128KB/s，不是1MB/s

1M带宽指的是1Mbps，也就是每秒1024K比特。带宽的单位是比特，下载速度的单位是字节，1字节等于8比特，换算下来1Mbps对应每秒128KB的下载速度。把它当成“每秒1MB”是最常见的理解错误，很多人就是这么高估自己带宽的。

后面所有估算都建立在这个数字上，记住两组换算就够了：

- 1Mbps = 128KB/s，2Mbps = 256KB/s，10Mbps = 1280KB/s
- 需要的带宽（Mbps）≈ 每秒要传的字节数 × 8 ÷ 0.7。除以0.7相当于按七成线路利用率留余量，给网络开销和波动留出空间

举个例子，希望网站每秒能对外传输100KB数据，按公式是100×8÷0.7≈1143Kbps，对应1.2M左右的带宽。

## 1M带宽能带多少人在线？17人和200人两种说法都有道理

这两个数字经常把人绕晕，其实它们量的是不同的东西。

17人是这么算出来的：1M带宽=128KB/s，页面平均60KB，按“页面8秒内打开”的底线，一位访客在8秒里平均只占7.5KB/s的速率，128÷7.5≈17。也就是说，17人是“同一时间段里都在打开页面”的人数。标准收紧到5秒打开的话，这个数字降到11人左右。

200人说的是另一种口径：图片站、论坛站的1M带宽，大约能支撑200人左右同时在线。在线的大部分人只是在浏览、阅读，同一瞬间真正向服务器要数据的只有一小部分，所以在线人数可以远高于同时加载人数。

日常容量用“在线人数”的口径感受就行，但有一种情况必须按并发算：刚发了热帖，一大批人几乎同时点进来。举个例子，论坛页面30KB，200人同时涌入，要求3秒内全部打开，需要每秒2000KB的传输量，换算成带宽约16M；要求1秒内打开，就得48M。搞活动、推热帖之前，值得按这个方法把峰值估一遍。

## 带宽之外还要看月流量：1M带宽约等于每月150G流量

常见的经验换算比例是**带宽：流量≈1:150**，即1M带宽大致对应150G的月流量。理论上1M带宽一个月全速跑能到300G以上，150G相当于把闲时和波动都算进去的常规水位。这个换算有两个用法：一是选好带宽后，对每月流量水位心里有数；二是反过来，用月流量需求倒推带宽——估算网站每月要跑600G流量，对应的就是4M左右的带宽。

月流量指服务器每月经网卡上传和下载的总数据量，进和出都计入。买服务器时常见的三种计法，适合的人不一样：

- **计量计划**：给固定的月流量配额，超出部分额外付费，适合能预估流量、想控制成本的站点
- **不计量计划**：不限流量总量，但带宽速率有上限，适合平时占用高、不会全天跑满的场景
- **无限量计划**：连长期占满带宽也不额外收费，适合视频类、需要大规模持续传输的业务

能算清自己的流量就选计量；算不清或波动大，不计量是灵活和成本之间的折中；确实要长期跑满，再看无限量。

## 共享带宽和独享带宽，差价什么时候值得花

独享2M的含义是：不管你实际用多少，这2M固定分给你，任何时段都能保证256KB/s的速度。共享100M则是多个用户共用一条100M线路，空闲时段你可能用得很畅快，高峰期大家一起抢，单个用户分到的带宽通常在1M–5M之间浮动，挤的时候甚至不足1M。

普通内容站、流量不大的博客，共享带宽够用，没必要多花独享的钱。对下载速度敏感的业务——软件下载、文件分发这类——建议直接上独享，否则高峰期速度没保障。

带宽买小了最直接的表现是高峰期页面加载缓慢、卡顿，流量上来以后最先受伤的就是用户体验。不过在升级之前，值得先确认瓶颈真的在带宽。

## 两个能明显降低带宽需求的手段：CDN 和对象存储

CDN和静态缓存能把大部分并发压力从源站卸掉，效果很直观：以文字为主的博客，1M带宽本身容量有限，接入CDN后也能支撑日均2000IP左右的访问。网站并发突然变大的场景，CDN加静态缓存也是最常用的应对手段。

另一个是对象存储。下载类站点的文件如果全走服务器带宽，成本会非常高，把文件放到对象存储上分发是一种成本更低的做法。视频、音乐这类大文件业务，这个思路同样适用。

这两个手段用好了，同一档位的带宽能撑起的访问量会大不少，也是“1M带宽也能做站”的前提。

## 常见问题

**新网站一开始就买大带宽更保险吗？**

没必要。带宽只要真实、够用就好，新站从2M起步、不够再加，是最不容易浪费的买法。带宽是持续付费项目，起步就买大，多出来的部分每个月都在白花钱。

**带宽是不是越大越好？**

带宽越大，单位时间能传输的数据越多，高并发时越不容易卡顿，这一点没错。但实际体验还受网络延迟、服务器与用户之间的距离、线路设备等因素影响，带宽再大也不等于打开速度一定快。按实际需求选够用的档位就行。

**视频和直播站的带宽怎么估算？**

按并发人数乘以码率算，不能只看在线人数。两个参考数字：普通用户看视频平均需要80KB/s左右的下载速度；如果1000人并发、高清码率2Mbps、标清1Mbps、比例1:2，总输出带宽约800Mbps。这类业务对带宽是长期占用，按在线规模选档，50M只是下限。
